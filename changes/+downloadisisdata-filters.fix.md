Fix `downloadIsisData` filters removing test data needed to run the app tests. The 30-rule filter list written for de-centralized upstream kernel mirrors was also applied to the curated `isistestdata`, `base`, `legacybase` and `control` remotes, where it excluded 965 files from `isistestdata` (all of them test fixtures, breaking roughly 195 app test cases) and 10 detached PDS labels from `base`, while saving only 0.13% of the download. Filters are now selected per remote, leaving the kernel-mirror rules unchanged for the mission remotes they were written for. Several related bugs are also fixed: `--filter` raised `AttributeError`, the filter list was mutated globally so user rules compounded across missions in `downloadIsisData all`, the `--include` catch-all leaked into subsequent missions, and `main()` shadowed the parsed arguments.
